Your nuclear pilot.
Specialist agents. One connected project.

Explore one possible configuration: four specialist agents, connected evidence and coordinated reviews for your project team.

Build the pilot, step by step ↓
08 stagesExample configuration. Project-specific scope.Scroll to assemble ↓
01

Controlled foundation

Start with the owner’s knowledge.

Agree the pilot scope, infrastructure and access rules. Select a controlled set of project records, with revisions, sources and responsible reviewers.

02

Example agent 01

An agent that knows the project.

Configure a project agent around the approved design basis, systems and equipment. It helps locate context and trace how project records relate.

03

Example agent 02

An agent for licensing evidence.

Connect the project’s licensing documentation, such as PSAR or FSAR where applicable. The agent helps trace claims to supporting evidence and flags gaps for review.

04

Example agent 03

An agent for detailed design.

Connect working drawings, specifications and installation records. The agent helps compare revisions and identify differences from the approved project baseline.

05

Example agent 04

An agent for project requirements.

Build its knowledge from the applicable regulatory requirements, agreed standards and project commitments. Each finding points back to the relevant source and version.

06

Coordinated review

Four perspectives. One review loop.

A coordination layer routes questions and exchanges source-linked findings between agents. As approved records change, repeat the agreed checks and flag conflicts for human resolution.

07

Owner & oversight support

Give reviewers the evidence.

Bring linked findings to the owner, engineering reviewers and construction oversight teams. They can inspect sources, request corrections and record decisions; authorised people retain approval.

08

Operations & evaluation

Keep the knowledge useful.

Where included in the pilot, connect as-built records, change history and maintenance information. Test retrieval and cross-checking with the operating team, then agree any next phase.
